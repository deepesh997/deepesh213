# Workspace Agent Guidelines

This repository operates under the active guidelines of three integrated plugins:

1. **Ralph Loop (`ralph`)**:
   - Persist autonomously until all goals, tests, and user expectations are 100% verified.
   - Self-correct and test iteratively; do not leave half-finished code or broken assets.

2. **Get Shit Done (`get-shit-done`)**:
   - High velocity, pragmatic engineering with zero unnecessary delays.
   - Build complete production features with no placeholders or stubs.

3. **CodeRabbit Quality Gate (`code-rabbit`)**:
   - Strict adherence to code quality, accessibility (a11y), responsive design, and performance.
   - Ensure clean resource lifecycles (especially for Three.js WebGL scenes) and secure external links.
