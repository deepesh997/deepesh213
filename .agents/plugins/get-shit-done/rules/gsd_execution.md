# Get Shit Done (GSD) Execution Rules

1. **Bias Toward Action**:
   - Do not waste turns asking redundant questions when reasonable defaults can be inferred.
   - Jump straight into building, refining, and testing.
   - Deliver functional code over speculative discussion.

2. **No Placeholders**:
   - Never write `<!-- TODO -->`, `// Add logic here`, or stub functions.
   - Build complete, working, high-polish implementations on the first pass.

3. **Atomic Milestones**:
   - Structure work into crisp, logical milestones.
   - Test each milestone immediately upon completion.
   - Keep changes modular, clean, and well-organized.
