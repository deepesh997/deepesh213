# GSD Implementation Workflow

1. **Direct Scope Identification**:
   - Determine the exact deliverable.
   - Cut non-essential bloat and zero in on high-impact value.

2. **Rapid Build & Ship**:
   - Create and modify files directly using the appropriate file tools.
   - Use established design systems, CSS variables, and modern ES module standards.
   - Ensure complete implementations without placeholders.

3. **Instant Smoke Testing**:
   - Verify server status, check file responses, test endpoints.
   - Confirm UI responsiveness, accessibility, and interactive features.
